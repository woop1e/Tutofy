# Запуск Tutofy

## Требования

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) — установить и запустить
- [Node.js](https://nodejs.org/) v18+ (для фронтенда)
- [Git](https://git-scm.com/)

---

## 1. Клонировать репозиторий

```bash
git clone https://github.com/woop1e/Tutofy.git
cd Tutofy
```

## 3. Запустить бэкенд

```bash
cd tutofy/services
docker compose up --build -d
```

Первый запуск занимает 10–20 минут (скачивает образы и собирает Go-сервисы).

Проверить что всё запустилось:
```bash
docker compose ps
```
Все сервисы должны быть в состоянии `Up`.

---

## 4. Запустить фронтенд

```bash
cd tutofy/frontend
npm install
npm run dev
```

Открыть в браузере: **http://localhost:5173**

## Остановить проект

```bash
cd tutofy/services
docker compose down
```

Чтобы также удалить все данные (базы, файлы):
```bash
docker compose down -v
```

---

## Частые проблемы

**Docker не может скачать образы** — перезапустить Docker Desktop и попробовать снова.

**Порт уже занят** — закрыть другие программы использующие порты 8080, 5433, 9000.

**Сервис падает при старте** — подождать 30 секунд, Docker Compose автоматически перезапускает сервисы. Проверить:
```bash
docker compose logs <имя-сервиса> --tail=20
```
