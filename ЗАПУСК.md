# Запуск Tutofy

## Требования

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) — установить и запустить
- [Node.js](https://nodejs.org/) v18+ (для фронтенда)
- [Git](https://git-scm.com/)

---

## 1. Клонировать репозиторий

```bash
git clone https://github.com/woop1e/Tutofy.git
cd Tutofy
```

---

## 3. Запустить бэкенд

```bash
cd tutofy/services
docker compose up --build -d
```

Первый запуск занимает 10–20 минут (скачивает образы и собирает Go-сервисы).

Проверить что всё запустилось:
```bash
docker compose ps
```
Все сервисы должны быть в состоянии `Up`.

---

## 4. Запустить фронтенд

```bash
cd tutofy/frontend
npm install
npm run dev
```

Открыть в браузере: **http://localhost:5173**

## Тестовые аккаунты

Зарегистрироваться самостоятельно через **http://localhost:5173/register** (студент) или **/become-tutor** (репетитор).

> После регистрации репетитора нужно одобрить профиль через аккаунт администратора.

### Создание администратора

После первого запуска создать admin-аккаунт одной командой:

```bash
docker compose exec postgres psql -U tutofy -d auth -c \
"INSERT INTO users (id, email, password_hash, name, role, is_verified) VALUES (gen_random_uuid(), 'admin@tutofy.com', '\$2a\$10\$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LpMSrdBEjPi', 'Admin', 'admin', true)"
```

Затем войти на `/login`:
- **Email:** `admin@tutofy.com`
- **Пароль:** `password123`

Или зарегистрироваться обычным способом и сменить роль:
```bash
docker compose exec postgres psql -U tutofy -d auth -c "UPDATE users SET role='admin' WHERE email='ваш@email.com'"
```

## Остановить проект

```bash
cd tutofy/services
docker compose down
```

Чтобы также удалить все данные (базы, файлы):
```bash
docker compose down -v
```

## Подключение Google Календаря (для тьюторов)

Google Календарь используется для автоматического создания встреч Google Meet при подтверждении урока.

### Шаг 1 — Создать проект в Google Cloud

1. Открыть [console.cloud.google.com](https://console.cloud.google.com/)
2. Нажать **Select a project → New Project**, дать имя (например `Tutofy`)
3. Выбрать созданный проект

### Шаг 2 — Включить Google Calendar API

1. В боковом меню: **APIs & Services → Library**
2. Найти **Google Calendar API** → нажать **Enable**

### Шаг 3 — Создать OAuth 2.0 credentials

1. **APIs & Services → Credentials → Create Credentials → OAuth client ID**
2. Если попросит — настроить **OAuth consent screen**:
   - User Type: **External**
   - App name: `Tutofy`
   - Scopes: добавить `https://www.googleapis.com/auth/calendar.events`
   - Test users: добавить свой Gmail
3. Application type: **Web application**
4. Authorised redirect URIs: добавить `http://localhost:8080/auth/google/callback`
5. Нажать **Create** — скопировать **Client ID** и **Client Secret**

### Шаг 4 — Вставить в .env

Открыть `tutofy/services/.env` и заменить значения:

```
GOOGLE_CLIENT_ID=<ваш Client ID>
GOOGLE_CLIENT_SECRET=<ваш Client Secret>
GOOGLE_REDIRECT_URI=http://localhost:8080/auth/google/callback
```

### Шаг 5 — Перезапустить api-gateway

```bash
cd tutofy/services
docker compose up -d api-gateway
```

### Как использовать

1. Войти как **тьютор**
2. Перейти в профиль → **Connect Google Calendar**
3. Пройти авторизацию Google
4. После этого при подтверждении урока автоматически создаётся событие в Google Calendar с ссылкой на Google Meet

> **Важно:** OAuth consent screen в режиме **Testing** работает только для добавленных test users. Для всех пользователей нужно подать заявку на верификацию в Google (или оставить в тестовом режиме для разработки).

## Частые проблемы

**Docker не может скачать образы** — перезапустить Docker Desktop и попробовать снова.

**Порт уже занят** — закрыть другие программы использующие порты 8080, 5433, 9000.

**Сервис падает при старте** — подождать 30 секунд, Docker Compose автоматически перезапускает сервисы. Проверить:
```bash
docker compose logs <имя-сервиса> --tail=20
```
